Carroo — Design Direction
arroo

現行プロダクトのデザインシステム。墨色のレール、紙のような明面、意味を持つ緑と琥珀。

Concept

物流の「今どこか」が一目で分かる、静かな道具

Carrooは物流案件をTrabox・WebKitへ一括投稿する業務ツール。装飾ではなく状態（掲載中・成約・失敗）を色で語る。左の墨色レールが常に定位置を保証し、右の紙面が仕事の中身に集中させる。

Color

意味を持つ色だけを使う

ベースは紙とインクの明暗。アクセントはシグナルグリーン（進行・成功・掲載中）と琥珀（注意・処理待ち）の2色のみ。ライト/ダークで役割は変えず、明度だけ入れ替える。

Typography

OSネイティブ書体・数字は必ず等幅

游ゴシック／ヒラギノ角ゴをOS標準スタックで採用。Webフォント無し＝表示が速く、機種依存の崩れがない。金額・IDなど数字が並ぶ箇所は tabular-nums（.num）で桁を揃える。

Navigation

左レールは常に墨色――場所を問わず同じ

紙面がライト/ダークで入れ替わっても、レールは常に濃色で固定。「ここがCarrooの操縦席」という定位置の安心感を担保する。現在地は緑の縦バーで示す。

Components — Actions

ボタンは3段階、意図は色で語る

主＝塗り（シグナル）／副＝輪郭のみ／破壊的＝赤文字の輪郭のみ（塗らない）。送信は押下即スピナー化で二重送信を防ぐ。

状態はチップで語る

掲載中 成約 処理中 取下げ済

4状態固定のボキャブラリー。新しい状態を増やす時もこの4トーン（緑濃／緑淡／琥珀／グレー）から選ぶ。

岐阜三重

入力欄はフォーカス時にシグナルグリーンの縁＋ソフトなグロー。複数選択はチップ化して一覧性を確保。

ヘルプと注意喚起

❓ 自動投稿のしくみ
  • 毎朝7:00に自動投稿します。
  • 初期登録回数を指定すると作成直後にまとめて投稿できます。

折りたたみは緑アクセント＋回転する矢印で「開閉できる」ことを明示。警告・エラーは琥珀トーンで温度を分ける。

Principles

やること・やらないこと

Do色は状態を語るためだけに使う。緑＝進行/成功、琥珀＝注意。装飾目的の色は追加しない。
Don't新しい状態のために新しい色相を足さない。既存4チップ（live/met/wait/off）で表現できないか先に検討する。
Doレールは常に濃色で固定。紙面のみライト/ダークが入れ替わる。
Don'tレールをライトテーマで白くしない。「操縦席」の定位置感が失われる。
Do数字が並ぶ箇所は必ず .num（tabular-nums）＋右寄せ。
Don't送信ボタンをクリック後そのままにしない。即スピナー化必須（二重送信防止）。
